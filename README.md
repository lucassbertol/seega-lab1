## 📌 Overview

**SEEGA** is a terminal-based recreation of the classic [Egyptian board game Seega](https://en.wikipedia.org/wiki/Seega), developed in C. The game supports local multiplayer, a computer opponent, match saving, and a game history log.

Developed as the final project for the **Programming Laboratory 1** course — Information Systems, UFSM.

---

## ✨ Features

- 👥 **Player vs Player** — local match between two players
- 🤖 **Player vs Computer** — challenge the built-in AI
- 💾 **Save match** — save your progress and resume later
- 📋 **Match history** — review the results of previous games
- 📖 **Game rules** — access the rules directly from the menu

## 🚀 Getting Started

### Prerequisites

- GCC (or any compatible C compiler)

### 1. Clone the repository

```bash
git clone https://github.com/lucassbertol/seega-lab1.git
cd seega-lab1
```

### 2. Compile the project

```bash
gcc seega.c -o seega
```

### 3. Run the game

```bash
# Linux/macOS
./seega

# Windows
seega.exe
```
